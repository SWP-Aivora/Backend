# Aivora.Services

Business logic and domain services for the Aivora platform.

## Overview
This layer encapsulates the core business rules and orchestrates data movement between the API and Repository layers.

## Core Services
- **AIJobAssistantService**: AI-driven job refinement and suggestions.
- **IdentityService**: User registration and authentication logic.
- **JobService**: Job posting and management.
- **HiringService**: Proposal acceptance and project initiation.
- **Financial Services**: Wallet, Payments, and Milestone management.
